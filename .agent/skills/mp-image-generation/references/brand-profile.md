# Millennial Perfumer image constraints

Apply these supplied product-fidelity requirements to every image unless the user explicitly changes one for the current request:

- Preserve the exact bottle shape, proportions, and visible product details from the supplied product image.
- Preserve the exact label design, wording, spelling, line breaks, and placement. Do not invent, simplify, blur, or alter typography.
- Use a glossy black bottle and cap finish when that matches the supplied product image. Keep reflections physically plausible and prevent black-on-black detail loss.
- Create ultra-realistic, premium product photography. Match the reference image's visual direction without copying its protected branding or in-image text.
- No watermark, extra product logo, invented packaging text, warped label, duplicate bottle, malformed cap, or stray fingers/objects.

If a supplied product image conflicts with a rule above, treat the product image as the source of truth and flag the conflict before generating.
